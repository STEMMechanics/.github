# Getting help

First, read the repository's `README` and search its existing issues. Your
question may already have an answer.

If you still need help, open an issue using the most suitable form. Explain
what you are trying to do, what you have already tried and what happened. You
do not need to know the right technical words—we would rather have a clear,
honest description.

Please remember:

- GitHub repositories are mainly for project questions, bugs and ideas.
- Help is provided by people when they are available, so replies may take time.
- Never post passwords, access tokens or personal information.
- Possible security problems must be reported privately using
  [`SECURITY.md`](SECURITY.md).

If you are aged under 18 and need to contact somebody privately, ask a parent,
carer, teacher or another trusted adult to help.

For STEMMechanics programs and general enquiries, visit
[stemmechanics.com.au](https://www.stemmechanics.com.au/).
