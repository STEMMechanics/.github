# Security

Thank you for helping keep STEMMechanics projects and their users safe.

## Report a security problem privately

Please **do not** open a public issue for a possible security problem. Public
details could help somebody misuse the problem before it is fixed.

Use GitHub's **Report a vulnerability** button in the affected repository's
Security tab. If that option is unavailable, email
[hello@stemmechanics.com.au](mailto:hello@stemmechanics.com.au).

Include what you found, which project and version are affected, and safe steps
we can use to reproduce it. Do not access other people's information, disrupt a
service or keep testing after you have confirmed the problem.

If you are under 18, you may ask a parent, carer, teacher or another trusted
adult to help you make the report. Never include your home address, school,
phone number, passwords or access tokens.

## What happens next

We will acknowledge the report when we can, investigate it and work on a safe
fix. Please give us time to respond before sharing details publicly. Security
fixes normally target versions that are still actively supported.

For ordinary bugs, questions and feature ideas, please use the repository's
issue tracker instead.
